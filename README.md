# **RssReader**

A synchronized RSS/Atom feed reader: a core server aggregates and syncs feeds, with multiple client
applications (web, browser extension, mobile, etc.) for reading, filtering, and organizing them.

**Status:** early bootstrap — tooling and roadmap are defined; implementation hasn't started yet. See
[docs/ROADMAP.md](docs/ROADMAP.md) for scope/tech-stack decisions and milestones, and
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the system design.
