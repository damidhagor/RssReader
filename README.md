# **RssReader**

A synchronized RSS/Atom feed reader: a core server aggregates and syncs feeds, with multiple client
applications (web, browser extension, mobile, etc.) for reading, filtering, and organizing them.

**Status:** early bootstrap — architecture and feature scope are still being defined. See
[docs/ROADMAP.md](docs/ROADMAP.md) for the current plan once it exists, and
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the system design once decided.
